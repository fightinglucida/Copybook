# 技能之书 UI 原型

这是独立的设计审核原型。没有修改 Hugo 模板，也没有发布到 Cloudflare。

在本目录运行 `node server.cjs`，然后打开 http://127.0.0.1:18475。

可查看首页、分类、标签和任意帖子详情；可搜索、分页；详情页可查看百度和夸克网盘入口并复制提取码。导航「下载示例」打开已有两种下载链接的真实文章。

原型使用现有文章内容。旧帖日期来自 Git 首次加入记录；新文章正式开发时将优先使用 front matter 中的 date。这里只展示已有网盘链接，未提供的入口禁用。

仅保留浅色。桌面严格使用 NodeSeek 实测布局：白色主体 1080px，内边距 25px 30px；帖子内容宽 740px，右栏 260px，栏间距 20px。左分类栏在主体外侧，宽 100px，间距 20px。顶部导航高 40px，普通帖子行高 61.5px。没有首页介绍大区块。窄屏保留紧凑单列并通过菜单打开分类。

字体：Geist（SIL Open Font License）。图标：Phosphor Icons（MIT License）。

第三版视觉：32px 浅暖灰纸张网格，128px 网格分层；导航和全宽页脚统一使用 #232625 石墨深灰。帖子区与外置分类栏为白底。分类及标签使用鼠尾草绿、灰蓝、灰青、浅紫、米沙、藕粉、石灰七组低饱和色，同名标签跨页面配色一致。尺寸沿用第二版的 NodeSeek 实测值。

第四版：下载区位于完整正文之后，移除侧栏提前下载入口。使用 Marked + DOMPurify 展示 Markdown 图片、段落、引用、表格等；图片可点击放大，支持 Esc 关闭及手机缩放。单独的图文示例页只作排版审核，不写入原文章。首页头像由 DiceBear Notionists（CC0）按文章文件标识稳定生成，全部本地内嵌，不依赖外部头像 API。

第五版：标题下作者和发布时间靠左，标签同排靠右。下载面板与按钮均使用从百度网盘、夸克网盘官方站点取得的品牌 Logo，替换原文字占位图标。保留正文之后的下载区域。

第六版：提高强调色饱和度。分类与标签采用更清晰的绿、蓝、青、紫、琥珀和玫瑰色，头像背景同步增添色彩；频道及夸克按钮使用更鲜明的翡翠绿，百度按钮加强蓝色。保留浅色模式、深灰导航页脚、网格背景及白色正文，布局尺寸不变。
